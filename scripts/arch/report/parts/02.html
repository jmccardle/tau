Diffing a proposed change

--diff-against OLD.json compares the current selection with an earlier JSON dump and prints added (+), removed (-) and changed (~) classes and members. The demo diffed the agentsession_cursor selection against a hand-edited "old" dump (uml/simulated_old.json):

The workflow: dump the selection on the base commit with uml.py … --name before, apply the change, run the same selection with --diff-against before.json.

Limits observed

  • A structural Protocol implementation gets no edge (InMemorySessionLog → SessionLog).
  • Unions and type aliases are not expanded; nested classes are skipped.
  • Fields assigned outside __init__/__post_init__ are not listed.
  • Duplicate class names (SessionInfo ×3, SessionState ×2) need qualified names in --classes.
