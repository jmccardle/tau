This page measures the τ tree at one commit with thirteen scripts and the stock Python analysis tools, then describes the agent model those measures sit on: its vocabulary, its state machines, six executed scenarios, one traced turn and the configuration surface. Every figure and table names the script and command that regenerates it. The page describes the tree; it does not recommend changes.

0. The toolkit

Default status: ran. The scripts live in scripts/arch/ of the analysis worktree .claude/worktrees/arch-review. They are uncommitted: no branch carries them yet. Each takes --out DIR (default build/arch/<name> under the repo root) and writes JSON plus a Markdown or text summary.

WT=.claude/worktrees/arch-review          (in the repo checkout)
PY=venv/bin/python                         (the repo venv, Python 3.14.9)
export PYTHONPATH=$WT/tau-llm/src:$WT/tau-agent-core/src:$WT/tau-coding-agent/src:$WT/tau-jmfts/src
export HOME=<scratch> TAU_HOME=<scratch>/.tau
cd $WT

The venv's editable installs point at a different checkout, so PYTHONPATH selects the snapshot. A scratch HOME keeps the test suite and the probes away from the real ~/.tau.

Three kinds of figure on this page are not produced by a script. The 18 glossary state diagrams, the concept map and the six scenario key diagrams are hand-written DOT files kept beside this page's evidence (glossary/states_*.dot, glossary/concepts.dot, scenarios/key/key-*.dot), not in WT; they render through svg_theme.py. svg_theme.py leaves a graph-level label with literal font-family/font-size attributes (ran: three state diagrams); page/fig/make_figs.sh re-renders those three and rewrites that one text element's attributes to class="label-soft".
