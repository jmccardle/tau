# τ 0.17.3

A fix release: a skill or template whose frontmatter uses real YAML no longer stops τ from
starting. The wire protocol, the store and the Python API are unchanged.

## Fixed

- **A Claude Code skill with a folded `description:` stopped τ from starting.** Frontmatter was
  read as `key: value` lines, and a block scalar (`description: >-` followed by indented lines)
  was refused with `SkillFileError`. Every file problem stops the start, so one such skill in
  `~/.tau/skills/` or a project's `.tau/skills/` kept τ from running at all. Frontmatter is now
  read as the YAML block mapping a Claude Code skill writes, still without a YAML library:
  - `|` (lines kept) and `>` (lines folded) block scalars, with their chomping and indentation
    indicators;
  - plain values that go on over indented lines, folded into one;
  - `'single'` quoted values (`''` is a quote) and `"double"` quoted values with YAML's escapes,
    on one line or over several;
  - comments after a value, and a key's list or mapping (`allowed-tools:` then `- Read`, or
    `metadata:` then indented keys).

  Only `name`, `description`, `argument-hint` and `disable-model-invocation` are read; any other
  key is skipped whatever its value holds, so it never stops the start.
- `disable-model-invocation` also takes YAML's `True`/`TRUE` and `False`/`FALSE`.

## Changed

- A value read differently: a plain value's ` # comment` is now a comment, as in YAML, so
  `description: Fix it # TODO` is `Fix it`. A `#` not after a space (`C#`) is text, as before.
- One of the four keys read (`name`, `description`, `argument-hint`, `disable-model-invocation`)
  whose value is empty, a list or a mapping is refused with "must be text, not empty, a list or a
  mapping" (was "must be one line of text after the colon"). A quote that never closes, and an
  unknown escape in a double-quoted value, are refused naming the line.

## Upgrading from 0.17.2

- Nothing to do. A skill that 0.17.2 refused now loads; one that 0.17.2 loaded loads the same,
  apart from the comment rule above.

## Install

```bash
pip install 'ffwf-tau>=0.17.3'
pip install 'ffwf-tau[tokens]>=0.17.3'   # with local tokenizers
```
