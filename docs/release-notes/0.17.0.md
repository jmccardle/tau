# τ 0.17.0

## Summary

Two additions on top of 0.16.0:

- **The HTTP edge.** `tau serve` gains a second transport, so a browser page, an editor's webview,
  another container or another machine can drive a session without reaching its Unix socket. The
  design is [D29](../design/decisions/D29-http-edge.md). This was planned as 0.16.1, which was
  never released.
- **Images in tool results.** A tool can give the model an image: `read` returns image files, and
  an extension's function tool can return text and images together. The image travels through the
  session log, the walk and the providers to a model that can see. The design is
  [D30](../design/decisions/D30-images.md).

Images change the wire and the session file, so **`PROTOCOL` is 2** and the **store version is
2** (see Upgrading).

## Upgrading from 0.16

- **Clients.** A client built for protocol 1 is refused at `hello` with `ProtocolMismatch`.
  Regenerate it from `tau serve --schema`. `Outcome.Ok` without images is encoded as before
  (`{"Ok": "text"}`). With images it is
  `{"Ok": {"value": "text", "images": [{"mime", "sha256", "width", "height"}]}}`.
- **Sessions.** 0.17 opens 0.16 sessions as they are.
  - The first time 0.17 writes to a 0.16 session, it marks the session file as version 2. From
    then on, 0.16 refuses that session by name (`session file version 2; this build reads 1`).
  - A session that 0.17 only opens, reads or fails to load stays version 1.
  - To keep a session usable from 0.16, fork it first (`--fork`) and continue the fork.
- **The serve record** (`$TAU_HOME/serve/<session id>.json`) gains fields. Its field order changed,
  and `socket` is absent when the socket is off. Read it as an object.

## Images

- **Which models.** A model takes images only if its config says `"images": true`. Each built-in
  provider declares its per-image limits:

  | provider | bytes | pixels a side |
  |---|---|---|
  | OpenAI-compatible | 20 MiB | any |
  | Anthropic | 3.75 MiB | 8000 |
  | Gemini | 15 MiB | any |

- **`read`** returns a PNG, JPEG, GIF or WebP file as an image, judged by its bytes, not its name.
  The text part is the line `[image <path>: <mime> <W>x<H>, <N> bytes]`. It is the reference example
  of a tool that gives a model an image (`base_tools`).
- **Extension tools** may return `str`, `tau.Image`, or a `list` of both. The strings are joined
  by newlines, and the images follow in order. Sync and async tools both work.

  ```python
  from tau import Image


  async def screenshot() -> list[str | Image]:
      """Take a screenshot and show it."""
      path = await take_screenshot()  # your code: writes a PNG
      return [f"screenshot saved to {path}", Image.from_path(path)]
  ```

  - `Image(data)` takes bytes, which is the canonical form.
  - `Image.from_path(path)` reads the file when the tool returns, so the session does not depend on
    the file staying.
  - Anything that is not one of the four formats raises `BadImage`.
  - `Tree.image(image)` gives an image from an earlier node its bytes.
- **Nothing is dropped silently.**
  - A tool's images are checked against the model when the tool answers. A model without
    `images`, or an image over its provider's limit, turns the call into an `Err` that says what
    was refused and why, and keeps the tool's text. The model reads it, and the step goes on.
  - A branch that already holds images is refused before any request if it is moved to a model
    that cannot take them.
- **No resizing.** τ does not resize images. An image over the limit is an error that says so.
  Make a smaller copy and send that.
- **How each provider sends it.**
  - **OpenAI-compatible** (llama.cpp with mtmd, vLLM, OpenAI): the tool message stays text, and its
    images follow in a `user` message of `image_url` data URLs.
  - **Anthropic:** image blocks inside the `tool_result`.
  - **Gemini:** `inlineData` parts after the function responses. This is unverified against the
    live API.
- **Storage.**
  - Each image is kept once, as `images/<sha256>` beside the session's log.
  - The log holds only the reference.
  - A damaged image file is replaced the next time the same bytes are written.
  - A fork copies the images it walks.
- **Elsewhere.**
  - **Token counts** use the image's pixels, never its base64.
  - **`/prune`** keeps images on the newest turn only.
  - **Compaction** shows the summarizer the images it summarizes and keeps those of the kept tail.
  - **The terminal UI, `tau export` and the ratatui example** show an image as `[image WxH mime]`.

## The HTTP edge

- **`tau serve` listens on both** its Unix socket (as before) and HTTP on loopback, by default.
  `--no-unix` and `--no-http` turn one off; both off is an error.
- **The edge.** `GET /stream` opens a server-sent-events stream. Its first event is the connection
  id, then every response, `event` and `end`.
  - Each request is a `POST /stream/<connection id>`.
  - A `: ping` every 15 seconds keeps the stream open and finds a client that vanished. Its
    questions then go to the pool, as for a dropped socket.
- **Access.**
  - Every request carries `Authorization: Bearer <token>`.
  - A request from a web page (an `Origin` header) is refused unless `--allow-origin ORIGIN`
    names it. The flag is repeatable.
  - A `--host` that is not loopback needs `--allow-network`.
- **The port.** 3393 if it is free, else any free port. `--port N` binds exactly N or fails.
- **The serve record** (mode 600) gains `url`, `host`, `port`, `token` and the session's `name`.
- **A web client, served by τ.** Every `GET` that is not the wire serves a built web client's static
  files, with no token.
  - The files come from `--web-root DIR`, or from the `dist/` of an installed `tau_web` package.
  - The client reads the token from its URL's fragment and calls the wire from the same origin,
    which the edge allows.
  - With no client installed, `/` is a help page saying so.
- **The banner** names every endpoint on one line. On a terminal it adds the URL with the token in
  its fragment: `open: …` with a web client, `for a web client: …` without. `--quiet` leaves that
  line out.
- **Python.**
  - New: `RemoteClient.connect_http(url, token, client)` and `tau.HttpEdge`.
  - New: `Server.start(..., http=HttpEdge(...))`, whose `path` is now optional, with `server.url`
    and `server.token`.
  - New: `Started.serve(..., http=...)`.
  - `tau -p` and `tau -c` attach over HTTP to a server that has no socket.
- **Dependency:** `h11` is declared (httpx already brought it in).

## Not yet

- **Windows:** `tau serve` there is to listen over HTTP alone (`--unix` is refused already), but
  the rest of the serve path is not ported or tested on Windows yet (D29 Open 1).
- **Images:**
  - user images (`@file`, `send(images=)`, the edge's input);
  - a wire call that fetches an image's bytes, so a remote client can draw it;
  - resizing;
  - per-request image limits;
  - an MCP client.
- **Compaction with images:** a compaction model that cannot take images cannot summarize a part of
  a session that holds them. That compaction fails with an error that says so.
