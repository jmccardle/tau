# τ 0.16.1 (unreleased)

## Summary

`tau serve` gains a second transport, the **HTTP edge**, so a browser page, an editor's webview,
another container or another machine can drive a session without reaching its Unix socket. The
wire itself does not change: the same JSON-RPC messages, `PROTOCOL` 1 and the same
`protocol.schema.json`. The design is [D29](../design/decisions/D29-http-edge.md).

## What changes

- **`tau serve` listens on both** its Unix socket (as before) and HTTP on loopback, by default.
  `--no-unix` and `--no-http` turn one off; both off is an error.
- **The edge.** `GET /stream` opens a server-sent-events stream (its first event is the
  connection id, then every response, `event` and `end`); each request is a `POST
  /stream/<connection id>`. A `: ping` every 15 seconds keeps it open and finds a client that
  vanished; its questions then go to the pool, as for a dropped socket.
- **Access.** Every request carries `Authorization: Bearer <token>`. A request from a web page
  (an `Origin` header) is refused unless `--allow-origin ORIGIN` names it. A `--host` that is not
  loopback needs `--allow-network`.
- **The port.** 3393 if it is free, else any free port. `--port N` binds exactly N or fails.
- **The serve record** (`$TAU_HOME/serve/<session id>.json`, mode 600) gains `url`, `host`,
  `port`, `token` and the session's `name`; `socket` is present only when the socket is on. Its
  field order changed (`socket` is no longer first); read it as an object.
- **A web client, served by τ.** Every `GET` that is not the wire serves a built web client's
  static files, with no token: `--web-root DIR`, or the `dist/` of an installed `tau_web` package
  (tau-code's). The client reads the token from its URL's fragment and calls the wire from the
  same origin, which the edge allows. With no client installed, `/` is a help page saying so. No
  Node is needed to run it.
- **The banner** names every endpoint on one line, and on a terminal adds the URL with the token
  in its fragment: `open: …` with a web client, `for a web client: …` without (`--quiet` leaves
  it out).
- **Python:** `RemoteClient.connect_http(url, token, client)`, `tau.HttpEdge`, and
  `Server.start(..., http=HttpEdge(...))` (its `path` is now optional), `server.url`,
  `server.token`, `Started.serve(..., http=...)`. `tau -p` and `tau -c` attach over HTTP to a
  server that has no socket.
- **Dependency:** `h11` is declared (httpx already brought it).

## Not yet

- **Windows:** `tau serve` there is to listen over HTTP alone (`--unix` is refused already), but
  the rest of the serve path is not ported or tested on Windows yet (D29 Open 1).
